1. **Website Hội Nghị**: [http://fphhcm.edu.vn/bao-cao-tong-ket-nam-hoc/](http://fphhcm.edu.vn/bao-cao-tong-ket-nam-hoc/)

## Triển khai (Deployment)

Được triển khai trên GitHub Pages với HTML/CSS thuần túy, tối ưu hóa tốc độ tải trang, tương thích di động (iOS Safari, Android Chrome) và hỗ trợ in ấn mã QR.
